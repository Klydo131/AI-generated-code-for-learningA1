# 🚀 Quick Start Guide - Tech Stock News Notifier

## Get Started in 3 Steps!

### Step 1: Install Dependencies
```bash
pip install -r stock_news_requirements.txt
```

### Step 2: Run the Program
```bash
python stock_news_notifier.py
```

### Step 3: Start Tracking!
1. Choose option **2** to select stocks
2. Enter stock numbers (e.g., "1,5,9" or "all")
3. Choose option **3** to view detailed information
4. Read the news and analysis to help make decisions!

## 🎯 Quick Example

**Want to check Apple and Microsoft stocks?**

1. Run: `python stock_news_notifier.py`
2. Press `2` (Select Stocks)
3. Enter: `1,3` (AAPL is #1, MSFT is #3)
4. Press `3` (View Selected Stocks)
5. Review price, news, and investment signals!
